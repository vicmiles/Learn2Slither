These reports were generated by the program.

training.json records training from scratch for 30000 games with seed 42.
training-continued.json records 70000 additional games with environment seed 123.
The files ending in -evaluation.json record 200 evaluation games with seed 2026.
best-held-out.json records a separate 1000-game evaluation with seed 2027. Per-game results are stored in best-held-out.csv.
size15.json records 100 games on a 15 by 15 board with the same trained model and seed 2027.

mean_length is the mean length at the end of a game. mean_max_length is the mean of each game's peak length. reached_10_rate counts games that reached length 10 at any time. final_10_rate counts games that ended with length at least 10.

truncated counts games stopped by the step limit. These games are included in the statistics, so mean lifetime is not an uncapped estimate of time until death.

The bonuses directory contains measurements for all bonus length goals and four board sizes. bonus_final_rates uses final length. bonus_peak_rates uses peak length. Original reports created before the bonus update do not contain these additional fields. summary.json includes the model checksum and confirms that evaluation did not change the model file.

The test suite and flake8 check cover the project. The lobby, live board and results screen were inspected in the running application on macOS. Check Tkinter and the window layout again on the campus computer.
